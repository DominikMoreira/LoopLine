# LoopLine
LoopLine is a native iOS and iPadOS knitting companion app built with SwiftUI.
It helps knitters keep pattern projects organized, track their progress, and read instructions comfortably while knitting.

## Features
- Create projects from pasted text, PDFs, or images
- Track rows, repeats, and stitches
- Add project notes
- Read pattern content in a focused reading mode
- Support for iPhone, iPad, dark mode, and German localization

## Tech Stack
- SwiftUI
- SwiftData
- Swift Testing / XCTest

## Status
LoopLine is currently in active development and being prepared for its first App Store release.
